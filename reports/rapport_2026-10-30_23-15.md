### 1. L'Outil Clé : Le Notebook Google Colab "FastSub-0DH"

Hébergé gratuitement sur Google Drive/GitHub, il utilise les serveurs GPU T4 gratuits de Google pour transcrire n'importe quelle vidéo de 60 secondes en **moins de 5 secondes**.

#### Le Script Python (à copier-coller dans un notebook Google Colab gratuit) :

```python
# ==========================================
# 1. INSTALLATION DES DÉPENDANCES GRATUITES (Exécuter en 1 clic)
# ==========================================
!pip install -q faster-whisper

import os
from google.colab import files
from faster_whisper import WhisperModel

# ==========================================
# 2. UPLOAD DE LA VIDÉO / AUDIO
# ==========================================
print("👉 Uploadez votre vidéo TikTok/Reels :")
uploaded = files.upload()
video_name = list(uploaded.keys())[0]

# ==========================================
# 3. TRANSCRIPTION ULTRA-RAPIDE (GPU GRATUIT T4)
# ==========================================
print("\n⏳ Transcription IA en cours...")
# Modèle 'small' ou 'medium' : ultra précis en français/arabe/anglais
model = WhisperModel("small", device="cuda", compute_type="float16")

segments, info = model.transcribe(video_name, beam_size=5, word_timestamps=True)

# ==========================================
# 4. GÉNÉRATION DU FICHIER .SRT POUR CAPCUT
# ==========================================
srt_filename = os.path.splitext(video_name)[0] + ".srt"

def format_time(seconds):
    millis = int((seconds - int(seconds)) * 1000)
    mins, secs = divmod(int(seconds), 60)
    hours, mins = divmod(mins, 60)
    return f"{hours:02d}:{mins:02d}:{secs:02d},{millis:03d}"

with open(srt_filename, "w", encoding="utf-8") as f:
    for i, segment in enumerate(segments, start=1):
        start = format_time(segment.start)
        end = format_time(segment.end)
        text = segment.text.strip()
        f.write(f"{i}\n{start} --> {end}\n{text}\n\n")

print(f"\n✅ Terminé ! Langue détectée : {info.language} ({info.language_probability:.2%})")

# ==========================================
# 5. TÉLÉCHARGEMENT AUTOMATIQUE DU FICHIER .SRT
# ==========================================
files.download(srt_filename)
```
