### 1. Le Cœur Technique : Le "Bypass" Whisper via Google Colab (0 DH)

Le point de blocage numéro 1 de CapCut est la génération des **sous-titres dynamiques mot-à-mot**. CapCut gratuit permet toujours d'importer des fichiers `.srt` externes ou de styliser du texte, mais fait payer la génération automatique.

**La parade technique :** Utiliser un **Google Colab partagé** (exécuté sur les GPU Tesla T4 gratuits de Google).
* **Coût pour toi :** 0 DH (Google Colab est gratuit).
* **Coût d'API :** 0 DH (Whisper tourne directement en open-source sur le GPU alloué par Google).
* **Charge sur le PC utilisateur :** Zéro (tout tourne sur les serveurs de Google, fonctionne même sur un Chromebook ou un vieux PC portable).

#### Le Script Minimal (1 seul bouton "Play" pour l'utilisateur) :
Tu crées un notebook Google Colab public contenant ce code unique :

```python
# 1-CLICK AUTO-CAPTION (Whisper Word-Level SRT Generator)
!pip install -q git+https://github.com/openai/whisper.git

import os
import whisper
from google.colab import files

print("1. Choisis ta vidéo ou ton audio (mp4, mp3, wav) :")
uploaded = files.upload()
filename = list(uploaded.keys())[0]

print("2. Transcription IA en cours sur GPU gratuit Google...")
model = whisper.load_model("small") # Rapide, précis en français/arabe/anglais
result = model.transcribe(filename, word_timestamps=True)

# Génération du fichier SRT
srt_filename = os.path.splitext(filename)[0] + ".srt"
with open(srt_filename, "w", encoding="utf-8") as f:
    for i, seg in enumerate(result['segments'], start=1):
        # Format SRT standard
        start = f"{int(seg['start']//3600):02d}:{int((seg['start']%3600)//60):02d}:{seg['start']%60:06.3f}".replace('.', ',')
        end = f"{int(seg['end']//3600):02d}:{int((seg['end']%3600)//60):02d}:{seg['end']%60:06.3f}".replace('.', ',')
        f.write(f"{i}\n{start} --> {end}\n{seg['text'].strip()}\n\n")

print("3. Téléchargement de tes sous-titres :")
files.download(srt_filename)
```
